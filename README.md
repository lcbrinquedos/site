# Site LC Brinquedos

Site institucional estático, responsivo e pronto para publicação pelo GitHub + Netlify.

O projeto inclui a página inicial, uma página institucional completa em `sobre.html`, logo otimizado, favicon e um guia rápido de identidade visual em `GUIA-DE-MARCA.md`.

## Publicação

1. Envie todo o conteúdo desta pasta para a raiz do repositório no GitHub.
2. No Netlify, conecte o repositório.
3. Deixe o campo de comando de build vazio.
4. Use `.` como diretório de publicação.

O arquivo `netlify.toml` já contém a configuração necessária.

## Atualizações importantes

- A imagem principal é ilustrativa. Substitua-a por uma fotografia real da LC Brinquedos quando desejar.
- Confirme o WhatsApp e o e-mail antes de publicar.
